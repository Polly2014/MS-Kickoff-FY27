# Connector 舞团 · 创意方案

版本：2026-11-16 会话归档。本文区分已接受方向、保留候选和未定细节，供下一轮工具及剧本讨论接续使用。

## 1. 已接受的方向

- 参赛主体为 **Connector 团队**；Substrate 是最初讨论背景，不作为本片的并列主角。
- 必须具备 **Connector、Copilot、卡通、舞团**四个元素。
- 主故事采用 **穿屏组团 → 舞台群舞 → 首尾 callback**；用户尤其喜欢首尾呼应。
- 音乐方向采用 **Funk＋电子舞曲**。
- 角色体系采用 **Copilot、Connector 双主角＋舞团伙伴**。
- 最新调整：伙伴由各 Connector 对应产品的 **Logo 衍生卡通形象**，保留来源产品辨识度。
- 可爱外形需要配合有阵势、有反差、抓眼球的舞蹈。周星驰《功夫》《少林足球》的群舞得到明确认可。
- Joker 参考指 **2019 年《Joker》的楼梯舞**，强调舒展、释放、自由感。
- 几何连接波浪、大场面齐舞及尺度反转方向得到认可；尚未决定将哪些片段编入成片。

工作标题“连接成功，次元壁已断开”和所有英文标语均为候选文案。

## 2. 主故事骨架

以下是故事设计，不是锁定的分秒剧本。

### 开端：隔着屏幕的邀请

浅色 Copilot 界面里，卡通 Copilot 独自跳两拍，回头寻找舞伴。Connector 从显示器一侧探头、敲屏。两者第一次隔屏击掌，没能碰到。

Connector 将发光连接带接到屏幕边缘。第二次击掌穿透屏幕，鼓点落下，渐变光从手掌扩散。

### 发展：把不同世界接成一个舞团

Connector 拉着 Copilot 跳出屏幕，落到键盘或界面构成的空间。不同品牌入口依次亮起，对应的 Logo 卡通角色加入。

各成员先以自己的动作和节奏出场，再通过击掌、波浪或光带传递动作，逐渐形成同一支舞团。

### 自由阶梯：从界面走向舞台

Connector 把窗口卡片接成悬浮阶梯。Copilot 张臂、晃肩、侧踢、转身，沿台阶自由起舞；品牌伙伴跟进。台阶随着脚步亮起，镜头揭示它从电脑世界延伸到巨大的演出空间。

### 高潮：每个成员保持特色，全团共同起舞

双主角带领舞团，核心角色有简短展示动作，再汇入统一的招牌齐舞。选择少量动作参考形成一套舞蹈，不把全部候选拼成舞蹈串烧。

近景呈现角色性格，中景看完整舞步，远景揭示更大规模的连接网络、方阵或环形剧场。音乐随伙伴加入而逐层丰富。

### 结尾：接回开头

**基础 callback**：舞台大屏重现开头独舞的 Copilot。舞台上的 Connector 走到屏幕旁，重复开头的探头、敲屏和伸手。最后回到两只手即将击掌的相同构图，形成故事闭环。

**尺度反转候选**：拉远后发现宏大圆形舞台位于另一个巨型 Copilot 的指尖。小 Connector 与巨型 Copilot 伸手相触，切回开头的击掌构图。

基础 callback 与尺度反转的取舍、实际循环点及片尾字幕插入位置，待正式剧本阶段决定。片尾要求必须满足；不能只实现剧情循环却遗漏制作信息。

## 3. 角色与品牌设计

### 当前角色体系

- **Copilot**：团长，发起邀请、参与双人舞、带领全团。
- **Connector**：组团者与共同领舞，通过穿屏、连接光带和动作传递，把不同品牌伙伴接到一起。
- **品牌舞者**：每个选定的来源产品拥有自己的 Logo 衍生形象、主色、轮廓、性格与招牌动作。

“远看认轮廓，近看认 Logo，跳起来认性格”是当前造型提案。具体实现方式尚待设计讨论。

统一身体比例、材质、舞鞋或团服轮廓；品牌差异通过标志性形状、配色、头饰、衣领、配件体现。角色需要足够长的四肢与清楚的关节轮廓，以便看清舞步。

### 非定案示例

| 品牌示例 | 曾讨论的造型方向 | 动作性格 |
| --- | --- | --- |
| GitHub | 从 Octocat 发展完整舞者 | 灵巧、快速脚步、穿插换位 |
| Jira | 蓝色几何造型融入头饰和夹克 | 精确卡点、机械舞 |
| Confluence | 交汇形状形成飘带或双袖 | 身体波浪、动作传递 |
| Salesforce | 云朵轮廓成为头部或蓬松外套 | 弹跳、腾空 |

以上仅是会话中的示意，**不表示已经选定该品牌、核实相应 Connector 范围或确定具体形象**。优先从团队实际代表产品及现场观众熟悉的品牌中选成员。

核心角色数量建议为 4–5 个品牌伙伴加双主角；大场面扩展方阵。数量仍是建议。

### 被最新设定替代的早期角色

早期“文档、知识页、工单、代码”的泛化伙伴，以及 Excel 八爪鱼、Wiki 长颈鹿等“企业山海经”怪物，不再作为主角色方案。用户认为山海经怪物与产品关联割裂。其有用的动作或空间创意可继续借用。

## 4. 配色与视觉

方向：**浅色界面开场 → 连接触发颜色 → 深色舞台承托 Copilot 渐变光**。

以下是从用户参考图延伸的影片建议色板，**不是官方品牌规范或精确取色结果**。

| 用途 | 建议色值 | 画面应用 |
| --- | --- | --- |
| 界面与基础服装 | 暖白 `#F7F8FC` | 清晰、轻盈的开场 |
| Connector 光带 | 电光青 `#24C8ED`、钴蓝 `#3565ED` | 连接线、袖口、动作轨迹 |
| Copilot 点缀 | 紫 `#8155E8`、珊瑚粉 `#F36DA0` | 内衬、肩部、舞台光 |
| 高潮高光 | 橙金 `#FFB454` | 击掌、鞋底、落拍 |
| 大舞台背景 | 深靛蓝 `#151C38` | 突出角色与渐变光 |

每个品牌伙伴优先保留其自身主色；全团通过服装结构和材质统一。渐变集中在连接、舞台和动作特效，避免所有角色全身彩虹导致辨识度下降。

造型候选仍包括：未来功夫服卡通高手、潮玩偶像团。约 3.5 头身、织物服装、柔和立体材质都是待验证建议，尚未确定最终美术形式。

## 5. 音乐与动作候选库

### 音乐方向

- Funk 弹跳贝斯、拍手、明亮合成器，高潮加入更有力量的电子鼓。
- 建议先以 120 BPM、4/4 拍试编；尚未锁定。
- 开场保留键盘声、弹指和轻量节奏；穿屏击掌是明确的入鼓点。
- 每位品牌伙伴加入时可增加一个声部，全员连接后形成完整音乐。
- 脚步、击掌、衣摆和光带音效需要参与编舞；允许抽掉音乐的短停顿制造反差。
- 歌词可少量使用，候选为“Link up. Step out. Move together.”；未定案。
- 音乐首尾动机可以呼应，但需与正式片尾安排一起设计。

### 舞蹈与场面参考

| 参考 | 已讨论的用途 |
| --- | --- |
| 《功夫》开场群舞 | 整齐踏步、摆肩、甩臂、突然定格；正式舞团出场的阵势 |
| 《少林足球》街头群舞 | 普通角色突然成为舞者，严肃表情与放开身体之间的喜剧反差 |

| 《变相怪杰》Cuban Pete | 节奏逐个传递，原本认真工作的伙伴控制不住地加入 |
| MJ《Smooth Criminal》 | 全员前倾到桌沿，Connector 光带绷紧接住，转成跨空间滑步 |
| 《RRR》Naatu Naatu | Copilot 与 Connector 搭肩同步踩键，每一步点亮新入口 |
| OK Go《Here It Goes Again》 | 卡片、窗口和传送带式舞台参与队形变化 |

## 6. 其他保留候选

- **《Connector，开团！》**：传送门召唤＋宇宙舞蹈擂台。小工程师召集不同世界的舞王，Copilot 与伙伴形成完整舞团。用户明确要求保留。
- **隐藏大佬舞团**：普通伙伴依次揭晓舞王身份，以短剧反转突出知识价值。
- **舞团跳出屏幕**：当前主方案的基础，核心吸引力是突破界面和首尾呼应。
- **万物加入舞团**：音箱、灯、地板、舞台乃至星球逐级加入，作为规模升级的灵感储备。

## 7. 下一轮需要决定

1. 核心品牌成员名单、来源 Logo 和各成员的动作性格。
2. Connector 自身用怎样的形象、是否有官方可用视觉素材；Copilot 如何从品牌元素衍生完整角色。
3. 最终美术风格、服装、比例及角色一致性方案。
4. 图像、视频、舞蹈、音乐、剪辑工具，以及可用预算、额度和制作时间。
5. 基础 callback 与巨型指尖反转的具体实现及取舍。
6. 总时长分配、片头片尾、音乐节拍、分镜和生成片段切分。
7. 双人接触、复杂脚步、群舞同步、Logo 稳定性、手指与尺度转场的小样验证。
8. 正式片名、团队展示名称、口号、主创名单、提交路径及截止时刻。

正式剧本和工具选择应在以上讨论后单独形成版本；本次归档不把建议值误写成制作定案。
