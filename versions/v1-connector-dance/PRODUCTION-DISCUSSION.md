# 制作讨论 · 音乐与编舞结构

日期：2026-11-16。状态：制作建议草案，待 Baoli 反馈；不替代创意方案中的已确认决定。

## 核心建议

一首连续舞曲、一套有重复记忆点的主舞、随故事推进变化队形与动作力度。影片分场景，制作按镜头分段生成，但观众听到连续配乐、看到同一支舞团的连贯表演。

已有电影和舞台参考分别提供自由感、群舞阵势、动作传播和视觉反转，不直接组织成每段换风格、换歌的串烧。

## 主舞草案

先以 120 BPM、4/4 拍试编。一个 16 拍主舞约 8 秒；后续按实际音乐及小样调整，不保证生成模型能精确执行每拍。

| 拍数 | 动作意图 | 视觉对应 |
| --- | --- | --- |
| 1–4 | 左右踏步、压肩，动作轮廓鲜明 | 建立全团共同节奏 |
| 5–8 | 向舞伴伸手、收回牵引 | 邀请与连接；触发窗口或光带 |
| 9–12 | 手臂波浪，经身体传向下一位 | 知识与节奏沿网络传递 |
| 13–16 | 侧滑、转向、统一定格 | 完成换位，并为下一乐句留接口 |

在双人、少人数和大舞团场景中复现同一动作主题。前倾、踢腿等高难动作作为可替换亮点，不要求主舞同时容纳全部参考。品牌成员的个性通过姿态、动作幅度和短暂展示体现。

## 时长试排

| 时间 | 情节／音乐 | 编舞安排 |
| --- | --- | --- |
| 0–8 秒 | 片头团队名称、独舞、敲屏与击掌 | 轻量主舞动机，建立首尾构图 |
| 8–16 秒 | 穿屏后双主角开始配合 | 第一次完整 16 拍主舞 |
| 16–24 秒 | 品牌伙伴陆续接入，增加音乐声部 | 同一主舞的接力与人数变化 |
| 24–32 秒 | 自由阶梯，向正式舞台推进 | 保持节拍，加入舒展、侧踢和转身 |
| 32–44 秒 | 全团高潮与几何波浪，揭示规模 | 重复主舞 8 秒，再做 4 秒扩展传播 |
| 44–48 秒 | 回到敲屏／击掌构图 | 基础 callback；尺度反转是否能容纳需分镜验证 |
| 48–60 秒 | 制作信息与 Prompt | 保留音乐尾段，具体布局待确定 |

这只是时间预算，不是正式分镜。十二秒片尾是否足以展示实际使用的原始 Prompt，须在 Prompt 清单形成后按实际内容量验证；不能默认以二维码或外链替代邮件要求。必要时减少剧情和动作段，给片尾留足时间。

故事闭环与播放器无缝循环是两件事。本试排先保证情节首尾呼应；最终一帧到第一帧的无缝播放不能在片尾布局确定前承诺。

## 制作顺序与验证

1. 收到核心品牌名单与可用工具信息后，比较实际可用工具；验证动作／音频参考、角色一致性等功能，不只依据 skill 示例判断支持情况。
2. 选定音乐样段并建立节拍标记，再写详细动作与镜头，不把各片段自带音乐拼成最终音轨。
3. 确定双主角及一个品牌伙伴的参考形象，先做一段约 8 秒、正面或轻微侧面、全身可见的主舞小样。
4. 检查品牌可识别、成员不互换、身体不融合、脚步与鼓点基本对齐，以及两次主舞能保持同一动作特征。提示词不能保证零变形，仍需挑选与修正。
5. 小样通过后，再测试多人波浪与穿屏接触。舞台、特效和大范围运镜逐步增加，不在第一次测试中同时要求所有难点。
6. 按镜头生成短素材，保留动作方向、出入画位置和姿态衔接；剪辑统一配乐、音效与节拍。字幕和精确标志可在后期合成。
