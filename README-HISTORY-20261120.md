## 当前创意概述

Copilot 在界面中独自跳舞。Connector 与它击掌、打通屏幕，再将不同品牌世界的卡通角色接到一起，组成舞团。舞团经过发光窗口阶梯进入大舞台，以群舞表现连接带来的共同创造。结尾回到开头的敲屏、击掌构图，形成首尾 callback。

**最新角色设定：每个 Connector 对应产品的 Logo 衍生一个有品牌辨识度的卡通舞者。** 早期的文档、工单、代码泛化角色仅保留为创意演进记录，不作为当前主方案。

## 下一轮讨论顺序

1. **品牌成员与造型**：确定最有团队代表性的 Connector 名单；选择核心舞者和大场面背景成员；讨论 Logo 如何转化为形象。
2. **工具与可行性**：讨论角色设计、角色一致性、舞蹈生成、运镜、音乐生成、剪辑和合成工具；确认可用账号、额度、时间与预算。
3. **音乐结构**：确定节拍、乐句、高潮、击掌音效、首尾衔接及片尾安排。
4. **具体视频剧本**：把主线压缩到一分钟内，确定每个镜头的时长、角色、舞步、运镜、转场和字幕。
5. **小样与成片**：先验证角色识别、双人接触、群舞同步和循环构图，再安排正式素材生成与剪辑。
